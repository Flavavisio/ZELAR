# Zelar

Plataforma de acompanhamento domiciliário de idosos com planta 2D e sensores Aqara.

**Estado:** projeto em desenvolvimento. A integração real com o Aqara Hub M3, deteção de quedas e notificações de emergência ainda requerem implementação e validação física. Não utilizar como sistema de segurança ou emergência.

## Plano inicial

- Gestão de habitações e divisões.
- Registo de sensores Aqara e associação a divisões.
- Estados da planta 2D e histórico de eventos.
- Integração Matter com Hub Aqara M3 e integração separada de FP2 via protocolo compatível.
- Alertas e permissões para familiares e cuidadores.

Não guardar credenciais nem dados pessoais reais neste repositório público.
